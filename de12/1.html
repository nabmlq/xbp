Web制作を支える2つの基本

はじめに Git HTML まとめ

01. はじめに

Webサイトを作ったり、プログラムを開発したりするときには、 さまざまな技術が使われています。 今回は、その中でも基本となる Git と HTML について調べました。

Gitはファイルの変更を管理するための仕組みで、 HTMLはWebページの構造を作るための言語です。 役割は違いますが、どちらもWeb制作を支える大切な技術です。

02. Gitとは？

Git（ギット）とは、ファイルの変更履歴を記録し、 管理するためのバージョン管理システムです。 主にプログラムの開発で使われています。

なぜGitが必要なのか

例えば、レポートやWebサイトを何度も修正すると、 「最新版」「最新版2」「本当の最新版」のように ファイルが増えてしまうことがあります。 Gitを使うと、変更を記録しておけるため、 過去の状態を確認しやすくなります。

Gitの仕組み

① ファイルを作る
→
② 変更を記録する
→
③ 履歴を確認する

変更を記録しておけば、いつ、どのような変更をしたのかを 振り返ることができます。必要に応じて過去の状態を 参考にしたり、以前の状態に戻したりすることもできます。

Gitでできること

  • ファイルの変更履歴を記録する
  • 以前のバージョンと比較する
  • 問題が起きたときに過去の状態を確認する
  • 複数人で開発するときに変更を共有する

GitとGitHubの違い

名前 役割
Git ファイルの変更履歴を管理する仕組み
GitHub Gitで管理したデータを保存・共有し、共同開発を助けるサービス
自分なりの理解： Gitは、ファイルの「変更の記録を残せるノート」のようなものだと考えました。 間違いに気づいたときや、複数人で作業するときに役立つ仕組みです。

03. HTMLとは？

HTMLは「HyperText Markup Language」の略で、 Webページの構造や内容を作るためのマークアップ言語です。 見出し、文章、画像、リンクなどを指定するときに使います。

タグ・要素・属性の違い

  • タグ：内容を囲んだり、要素の種類を示したりする記号
  • 要素：タグとその中の内容などを合わせたまとまり
  • 属性：要素に追加情報を設定するもの

例① 文章を表示する

<p>こんにちは！</p>
ブラウザでの表示例：

こんにちは！

<p> は文章の段落を表すタグです。 開始タグと終了タグで文章を囲むことで、段落として扱われます。

例② リンクを作る

<a href="https://www.google.com">
  Googleへのリンク
</a>
ブラウザでの表示例：

Googleへのリンク

<a> はリンクを作るタグです。 href 属性にリンク先のURLを指定します。

よく使うHTMLタグ

タグ 役割
<h1> 大きな見出し
<p> 文章の段落
<a> リンク
<img> 画像
<ul> と <li> 箇条書きのリスト
<table> 表

HTMLとCSSの関係

HTMLがWebページの構造を作るのに対して、 CSSは文字の色や背景、配置などのデザインを整えます。 このページも、HTMLで内容を作り、CSSで水色と紺色を使った デザインにしています。

自分なりの理解： HTMLはWebページの骨組み、CSSはその見た目を整えるものだと考えました。 役割を分けることで、内容とデザインを整理しやすくなります。

04. まとめ・学んだこと

Git：ファイルの変更履歴を記録・管理する。

HTML：Webページの構造や内容を作る。

CSS：Webページの見た目を整える。

今回調べてみて、普段見ているWebサイトも、 文章や画像を並べるだけでなく、HTMLで構造を作り、 CSSでデザインを整えていることが分かりました。 また、Gitを使うと変更履歴を残せるため、 Web制作を安全に進めたり、チームで協力したりしやすくなると理解しました。
